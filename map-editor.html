Map editor

Marks where each location sits on a game's map and writes data/maps.json. Pick a map, click a location in the list, then drag on the map to draw a box over it (several boxes per location are fine). When you're done press Download maps.json and put it in data/. Your work is also kept in this browser as a draft. Blue = other locations already done, red = the selected one.

Getting boxes to line up. Some maps (Sinnoh) are not drawn on a tidy 8 px grid, so snapping to 8 puts every box in the wrong place. Use one of these: Grid 0 (free drawing) with Snap to existing box edges ticked, so new boxes click onto the edges of the boxes already there; or enter the real tile size (decimals are fine, Sinnoh is about 7.2) and use Offset X / Y until Show grid lines sit on the map's tiles. Hover to see the location under the pointer; Shift + click selects a marked location without drawing; Alt + click deletes the box of the selected location under the pointer; arrow keys nudge the whole selected location by 1 px (hold Shift for 5 px). If the map image isn't in assets/maps/ yet, use Preview image….

Honey trees (Sinnoh map). The 🌳 entries at the top of the list are the trees from data/honey.json. Select one, then click the map to put its icon there (the old position is replaced), or drag a box. Arrow keys nudge it, Alt + click or Clear this location removes its position, Add honey tree creates a new one and Delete honey tree removes it completely. Press Download honey.json and put the file in data/ (separate from maps.json). The order of the list is the order shown on the site.
