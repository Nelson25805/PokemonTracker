Map editor

Marks where each location sits on a game's map and writes data/maps.json. Pick a map, click a location in the list, then drag on the map to draw a box over it (several boxes per location are fine). With a grid size set, boxes snap to whole tiles, so they match the in-game look. When you're done press Download maps.json and put it in data/. Your work is also kept in this browser as a draft. Blue = other locations already done, red = the selected one. Hover over the map to see the name of the location under the pointer and an outline of all of its boxes (hover a list entry to outline it on the map too); Shift + click a marked area to select that location without drawing. If the map image isn't in assets/maps/ yet, use Preview image… to load it from your computer; the file name in data/maps.json is what the site will use.
